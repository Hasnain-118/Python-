# 🌤️ Weather Station

[![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)](https://www.python.org/)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.28+-red.svg)](https://streamlit.io/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

A simple, elegant weather dashboard built with Streamlit that provides real-time weather information for any city worldwide.

## ✨ Features

- 🌍 **Global Coverage** - Get weather for any city in the world
- 📊 **Real-time Data** - Live weather updates from wttr.in API
- 🎨 **Clean Interface** - Beautiful, intuitive user interface
- 📱 **Responsive Design** - Works on desktop and mobile devices
- 🌡️ **Weather Metrics** - Temperature, humidity, wind speed, and conditions
- 💡 **Smart Advice** - Get personalized weather recommendations
- ⚡ **Fast & Lightweight** - Quick responses with minimal loading time
