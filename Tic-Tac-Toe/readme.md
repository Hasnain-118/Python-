# Tic-Tac-Toe Game with AI

A simple yet interactive Tic-Tac-Toe game built with Streamlit, featuring an AI opponent for single-player mode.

## 🎮 Game Overview

This is a classic Tic-Tac-Toe (Noughts and Crosses) game where you play against an AI opponent. The game features a clean interface, real-time updates, and intelligent AI moves.

## ✨ Features

- **Single Player Mode**: Play against an AI opponent
- **Interactive Interface**: Click on any empty cell to make your move
- **Real-time Status Updates**: Clear display of game progress and results
- **Smart AI**: Random but strategic AI moves
- **Game State Management**: Tracks board state, player turns, and game completion
- **Restart Functionality**: Reset the game at any time
- **Winner Detection**: Automatically detects wins, losses, and draws

## 🎯 Game Rules

1. Player 1 (You) plays as **X**
2. AI plays as **O**
3. Take turns placing your symbol on the 3x3 grid
4. First to get 3 in a row (horizontal, vertical, or diagonal) wins
5. If the board fills up without a winner, it's a draw

## 🛠️ Technology Stack

- **Python**: Core programming language
- **Streamlit**: Web application framework for the UI
- **NumPy**: For board representation and array operations
